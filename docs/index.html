Read-only · one binary · no runtime

Feather
opens before you blink.

A document viewer for PDF, EPUB, comics and images. One 9.7 MB binary, no service behind it, no cloud in front of it — a keystroke away, and gone when you close it.

What it refuses to do

A viewer that grows features stops opening before you blink.

No editing

No annotation, no forms, no signing, no saving. Open, read, close.

No cloud

Nothing leaves the machine. No account, no sync, no telemetry, no update check.

No plugins

A format is supported when a pipeline ships with it, not when someone installs one.

And what it does not do yet

The gaps are on the roadmap with their blockers, not in a footnote.

PDF text is not selectable

hayro renders pages but exposes no glyph-to-character mapping. EPUB, Markdown and text are selectable and searchable today.

Latin text only

No shaping yet, so Devanagari, Arabic and Thai come out wrong. The fix is skrifa and harfrust; the plan is written, the code is not.

No tray icon

It needs GTK on Linux. The right answer is a D-Bus status item, which is its own piece of work.

How to run it

Prebuilt archives for Linux, Windows and macOS are on the releases page, each with a SHA-256 beside it.

# from source
cargo run --release -p feather-app -- document.pdf

# look at it without a display
feather-viewer --screenshot out.png --page 41 comic.cbr

# register with the desktop — a candidate, never the default
packaging/linux/install.sh

] [ next, previous tab

n open in a window of its own
Ctrl Alt F summon from anywhere
